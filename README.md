# 🌐 DevForum

Uma plataforma de fórum e debates estilo Reddit, desenvolvida puramente com tecnologias web frontend.

🔗 **Aceda ao projeto online:** [Clique aqui para ver o site](https://raul-paulino.github.io/forum-livre/)

---

## 🚀 Funcionalidades
* **Autenticação:** Sistema de login e cadastro persistido com `localStorage`.
* **CRUD de Posts:** Crie, leia, edite e exclua as suas publicações em tempo real.
* **Comentários:** Seção interativa para debater e responder publicações.
* **Curtidas (Likes):** Sistema de votos nas postagens.
* **Filtros e Busca:** Pesquisa instantânea e separação por categorias.
* **Responsivo:** Adaptado para computadores e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5**
* **CSS3** (Flexbox, Grid, Variáveis e Dark Mode)
* **JavaScript (Vanilla)**
* **Browser LocalStorage**
